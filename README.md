# UtaDeck (MVP)

カラオケ中に「次なに歌う？」を最短で決めるための、スマホ向け持ち歌管理アプリです。  
ローカル保存（`localStorage`）で動くため、ログイン不要ですぐ使えます。

## 実装前整理（簡易）

1. **より良いアプリ名案**
   - UtaDeck（採用）
   - KeyPocket
   - VocalLoadout
   - UtaSnap

2. **MVPで削る候補**
   - 今回は要望どおり10機能をすべて実装。AIセットリスト・共有・統計グラフは後回し。

3. **データ項目の不足チェック**
   - MVPは要件を満たす。
   - 将来拡張用に `createdAt`, `updatedAt` を保持。

4. **UI/UX改善案**
   - 片手操作優先で下部ナビ固定。
   - 検索/絞り込みを一覧の最上部に集約。
   - カードタップで詳細遷移。

5. **有料化しやすい機能**
   - AIセットリスト自動生成
   - クラウド同期・バックアップ
   - 統計ダッシュボード
   - 共有テンプレート/画像出力

## MVP機能

- 曲追加 / 一覧 / 詳細 / 編集 / 削除
- 自分キー保存（-12〜+12）
- タグ管理（雰囲気・シーン）
- 場面別おすすめ（簡易スコアリング）
- ランダム選曲（条件付き）
- 歌唱履歴の記録（「今日歌った」）
- 空状態UI
- サンプルデータ初期投入
- スマホ向け下部ナビ

## 技術構成

- HTML / CSS / Vanilla JavaScript
- 保存先: `localStorage`
- サーバー不要

## 起動方法

### 方法A: ファイルを直接開く

`index.html` をブラウザで開くだけで動作します。

### 方法B: ローカルサーバー

```bash
python3 -m http.server 5173
```

その後、`http://localhost:5173` を開いてください。

## 使い方

1. **追加タブ**で曲を登録（曲名必須）。
2. **一覧タブ**で検索・絞り込み。
3. カードをタップして**詳細**へ。
4. 詳細の**今日歌った**で履歴追加。
5. **シーン**で条件を選び、おすすめ表示。
6. **ランダム**で条件抽選して1曲決定。

## バリデーション

- 曲名: 必須
- キー: -12〜+12
- 盛り上がり度: 1〜5
- 難易度: 1〜5
- 削除: 確認ダイアログあり


## 追加機能（タグ自動付与・歌詞要約）

- 曲追加/編集で **歌詞入力（任意）** と **歌詞を要約する** ボタンを追加
- 保存対象は `lyricsSummary` / `singingTips` / `autoTagReason` のみ（歌詞本文は非保存）
- **タグを自動付与** ボタンで、入力内容からキーワードベースで雰囲気タグ/シーンタグを推定
- `generateAutoTags(songInput)` / `summarizeLyrics(lyricsInput)` を分離し、将来AI APIへ差し替えしやすい構造
- 既存localStorageデータは正規化して不足項目を補完（後方互換）

## 無料AI導入（Ollama）

UtaDeck は無料で使えるローカルLLM **Ollama** に対応しました。

- 追加/編集画面の「無料AI設定」で `AI方式=ollama` を選択
- 既定値: URL `http://localhost:11434` / モデル `llama3.2:3b`
- 接続失敗時は自動で簡易ロジックへフォールバック

### Ollama セットアップ例

```bash
# 1) ollama をインストール（公式手順）
# 2) モデルを取得
ollama pull llama3.2:3b

# 3) 起動（通常は常駐）
ollama serve
```

> スマホから使う場合は、Ollama を動かすPCのIPを `Ollama URL` に設定してください（例: `http://192.168.1.10:11434`）。
